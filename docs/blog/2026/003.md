# 从文件 I/O 到线程:Linux 编程入门

这段时间在 `LinuxPrograming/` 下,按「文件读写 → 系统调用 → 线程」的顺序走了一遍,算是对系统编程有了个入门的印象。

## 文件 I/O

先把 `stdio` 全家桶逐个敲了一遍:

- `fgetc()` / `fputc()` — 一次一个字符
- `fgets()` / `fputs()` — 按行读写
- `fscanf()` / `fprintf()` — 格式化读写

一开始的 `fopen.cpp` 是最简单的打开文件:

```cpp
#include <stdio.h>
#include <string>
int main(int argc, char const *argv[])
{
    //str 字符串 文件名
    //mode 访问模式
    //return FILE* 结构体指针
    const char * filename = "HelloWorld.txt";
    FILE * file = fopen(filename,"r");
    if(file == NULL){
        printf("无对应文件！！\n");
    }else{
        printf("打开成功！！\n");
    }
    return 0;
}
```

`fgetc` 逐字节读到 `EOF` 为止:

```cpp
int get = fgetc(file);
//返回一个字节，以int形式
//如果出错或者读到文件末尾则返回EOF

while(get != EOF){
    printf("%c",get);
    get = fgetc(file);
}
```

这里有个容易踩的坑:`fgetc()` 返回的是 `int` 而不是 `char`,因为要留出 `EOF`(-1)的空间,用 `char` 装会丢数据。

`fscanf` 的返回值是成功匹配到的参数个数,这个细节一开始没注意:

```cpp
char name1[20];
char name2[20];
int num;
int flag = fscanf(file,"%s %d %s",name1,&num,name2);
printf("匹配到了%d个参数\n",flag);
```

## 小结

| 阶段 | 内容 | 收获 |
|------|------|------|
| 文件 I/O | fopen/fgetc/fscanf | 流式读写与 EOF 语义 |
| 系统调用 | unistd / system_call | 看见标准库下面的内核层 |
| 线程 | pthread_create | 迈入并发编程的第一步 |

进程、IPC、线程池这些更硬的内容在后面几篇里继续补。
