# socket 网络编程:从 TCP 握手上路

`socket_test/` 里从零开始摸 TCP 通信。学习路径是先跑通最小握手,再逐步加上收发数据:

- `tcp_mini_client_test.c` / `tcp_mini_server_test.c` — 最小版,只验证「连得上」
- `tcp_client.c` / `tcp_server.c` — 完整版,双向 `send`/`recv` 通信

## 服务端:五步走

`tcp_server.c` 把服务端的流程写得很清楚:**socket → bind → listen → accept → 收发**:

```c
int fd = socket(AF_INET,SOCK_STREAM,0);          // 1. 创建套接字
if(fd == -1){
    perror("socket");
    exit(1);
}
struct sockaddr_in server_addr;
server_addr.sin_family = AF_INET;
server_addr.sin_port = htons(9191);              // 端口：注意字节序！
server_addr.sin_addr.s_addr = htonl(INADDR_ANY); // 监听所有网卡

if(bind(fd,(struct sockaddr*)&server_addr,sizeof(server_addr)) == -1){ // 2. 绑定
    perror("bind");
    close(fd);
    exit(1);
}

if(listen(fd,10) == -1){                         // 3. 监听
    perror("listen");
    close(fd);
    exit(1);
}
printf("Waiting for connect...\n");

int client_fd = accept(fd,NULL,NULL);            // 4. 接入客户端
if(client_fd == -1){
    perror("accept");
    close(fd);
    exit(1);
}
printf("Client connected!\n");

char buf[1024];
ssize_t n = recv(client_fd,buf,sizeof(buf)-1,0); // 5. 收数据
if(n > 0){
    buf[n] = '\0';
    printf("Received:: %s\n",buf);
    char *response = "Hello from server";
    send(client_fd,response,strlen(response),0); //    再发回去
}
```

每个失败路径都带 `perror` + `close(fd)` 清理,这份习惯保持到了后面所有代码里。

## 客户端:主动出击

`tcp_client.c` 是另一条线:**socket → connect → 收发**:

```c
int client_fd = socket(AF_INET,SOCK_STREAM,0);
if(client_fd == -1){
    perror("socket");
    exit(1);
}
struct sockaddr_in target_addr;
target_addr.sin_family = AF_INET;
target_addr.sin_port = htons(9191);

if (inet_pton(AF_INET, "127.0.0.1", &target_addr.sin_addr) != 1) {
    perror("inet_pton");
    close(client_fd);
    return 1;
}
if(connect(client_fd,(struct sockaddr*)&target_addr,sizeof(target_addr)) == -1){
    perror("connect");
    close(client_fd);
    exit(1);
}
printf("Server connected!\n");
char *message = "Hello from client";
send(client_fd,message,strlen(message),0);   // 发

char buf[1024];
ssize_t n = recv(client_fd,buf,sizeof(buf)-1,0); // 收
if(n > 0){
    buf[n] = '\0';
    printf("Received:: %s\n",buf);
}
sleep(3);
close(client_fd);
```

`inet_pton` 把 `"127.0.0.1"` 点分十进制字符串转成二进制地址,转失败返回 0(检查的是 `!= 1`)。

## 三个要点

**1. 网络字节序。** `htons(9191)`、`htonl(INADDR_ANY)` 不能省。端口号和 IP 都是多字节整数,网络传输统一用大端(网络字节序),主机字节序要转过去。忘了 `htons` 的话,端口 9191 会变成一个莫名其妙的数,连都连不上——这是 socket 新手第一个坑。

**2. `accept` 才建立真正的连接。** `listen` 只是让内核监听,`accept` 才从等待队列里取一个客户端、返回一个专门通信的套接字。`accept` 之后用的是返回的 `client_fd` 收发,原来的监听 `fd` 还能继续 accept 下一个连接——「监听套接字 / 通信套接字」分离是这个阶段的核心概念。

**3. `SO_REUSEADDR`。** 服务器刚关掉、端口还在 `TIME_WAIT` 状态时,不加这个选项重启 `bind` 会失败:

```c
int opt = 1;
setsockopt(server_fd,SOL_SOCKET,SO_REUSEADDR,&opt,sizeof(opt));
```

这个小细节是踩过坑才记得住的。
